토큰 설정 도우미

주간 일정표의 열람용·편집용 토큰을 분리해 암호화하고, index.html에 바로 반영합니다. 모든 처리는 이 브라우저 안에서만 이루어지며 토큰과 암호는 어디에도 전송·저장되지 않습니다(토큰 점검 시 GitHub에만 요청).

1단계 · GitHub에서 토큰 두 개 만들기

  1. 아래 버튼을 누르면 이름·만료일·권한이 미리 채워진 토큰 생성 화면이 열립니다.
  2. Repository access에서 Only select repositories를 고르고 nambu-week만 선택합니다. (이 항목은 직접 골라야 합니다)
  3. Permissions → Repository permissions → Contents가 열람용은 Read-only, 편집용은 Read and write인지 확인합니다.
  4. 맨 아래 Generate token을 누르고, 나온 토큰(github_pat_로 시작)을 바로 아래 칸에 붙여넣습니다. 토큰은 이 화면에서 한 번만 보입니다.
열람용 토큰 만들기 (Read-only) 편집용 토큰 만들기 (Read and write)

2단계 · 토큰과 암호 입력

열람용 ("일정표 접속")

직원들에게 알려줄 접속 암호입니다. 이 암호로는 일정을 볼 수만 있습니다.

편집용 ("편집하기")

편집 담당자만 아는 비밀번호입니다. 접속 암호와 다르게 정하세요.

    3단계 · 암호화하고 index.html에 반영

    지금 쓰고 있는 index.html을 선택하면, 두 암호화 값만 바꾼 새 index.html을 내려받을 수 있습니다. 다른 내용은 그대로 유지됩니다.

    4단계 · 마무리

    1. 내려받은 index.html을 GitHub 저장소의 기존 index.html 자리에 올립니다(덮어쓰기).
    2. GitHub → Settings → Developer settings → Personal access tokens에서 예전 토큰을 Delete합니다. Tokens (classic) 목록도 꼭 확인하세요.
    3. 각 PC에서 일정표를 열어 "일정표 해제"를 한 번 누르고 새 암호로 다시 접속합니다.
    4. 편집하기로 들어갔을 때 "토큰이 같습니다" 경고가 더 이상 뜨지 않으면 완료입니다.
    이 도우미 파일은 비밀 정보를 담고 있지 않지만, 저장소에 올릴 필요는 없습니다. 내 PC에서 열어 쓰면 됩니다.
